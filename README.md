# 나의 저장고 — 단일 HTML PWA + 가족 공유 MVP

기존 `index.html` 화면을 유지하면서 PWA 설치와 Supabase 기반 가족 공유를 붙인 시작 패키지입니다.

## 포함 파일
- `index.html`: 기존 저장고 화면 + 로그인/가족 공유 연동 코드
- `manifest.json`: 홈 화면 설치 정보
- `service-worker.js`: 앱 화면 리소스 캐시
- `icons/`: PWA 아이콘
- `config.js`: Supabase 프로젝트 연결 정보 입력
- `supabase-setup.sql`: 인증 사용자/가족 공간/초대 코드/공유 데이터 테이블 및 RLS 정책

## 1. Supabase 설정
1. https://supabase.com 에서 무료 프로젝트를 만듭니다.
2. 프로젝트의 **SQL Editor**를 열고 `supabase-setup.sql` 전체를 실행합니다.
3. **Project Settings → API**에서 Project URL과 anon/publishable key를 확인합니다.
4. `config.js`의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 값을 교체합니다.
   - 브라우저에 공개 가능한 anon/publishable key만 사용하세요.
   - `service_role` 키는 절대 `config.js`나 HTML에 넣지 마세요.
5. Supabase **Authentication → URL Configuration**에서 Site URL과 Redirect URLs에 실제 Vercel 배포 주소를 등록합니다.
6. 이메일 인증을 켜두었다면 회원가입 메일을 확인한 후 로그인합니다. 테스트 단계에서는 Supabase Auth의 이메일 발송/확인 설정을 확인하세요.

## 2. Vercel 배포
1. 압축을 풀고 파일 전체를 기존 프로젝트의 배포 루트에 넣습니다.
2. `index.html`, `manifest.json`, `service-worker.js`, `config.js`, `icons/`가 같은 루트 기준으로 배포되는지 확인합니다.
3. 기존 프로젝트에 파일을 덮어쓰기 전에 원본을 백업하세요.
4. GitHub 연결 프로젝트라면 파일을 저장소에 반영하고 push합니다. Vercel이 새 배포를 완료하면 주소로 접속합니다.
5. Vercel이 단일 HTML 직접 업로드 방식이라면 기존 업로드 경로에 이 폴더의 전체 파일을 함께 배포합니다.

## 3. 부부가 함께 사용하기
1. 첫 번째 사용자: 회원가입 → 이메일 인증(설정된 경우) → 로그인
2. `마이페이지 > 가족 저장고`에서 가족 공간 이름을 입력하고 **가족 공간 만들기**
3. **초대 코드 만들기**를 눌러 코드를 복사해 배우자에게 전달
4. 배우자: 회원가입 → 로그인 → 같은 화면에서 코드를 입력하고 **참여**
5. 이후 재고/식단/장보기 변경은 가족 공간에 저장되고 다른 기기에 실시간 반영됩니다.

## 4. PWA 설치
- Android: Chrome에서 배포 주소 열기 → 메뉴 → 앱 설치 또는 홈 화면에 추가
- iPhone: Safari에서 배포 주소 열기 → 공유 → 홈 화면에 추가
- 앱 업데이트 후 캐시가 오래 남으면 브라우저를 완전히 닫았다 다시 열거나 사이트 데이터를 새로고침하세요.

## MVP 범위와 주의사항
- 기존 데이터는 각 브라우저의 localStorage에 있었습니다. 새 가족 공간을 처음 만들 때는 **그 기기에서 보이던 데이터**가 공유 저장소의 초기 데이터로 올라갑니다. 다른 기기에 있던 데이터가 자동 병합되지는 않습니다.
- 공유 데이터는 MVP 편의를 위해 하나의 JSON 상태 레코드로 저장합니다. 두 사람이 같은 순간에 서로 다른 내용을 수정하면 마지막 저장이 앞선 변경을 덮을 수 있습니다. 본격 사용 전 테스트하고, 다음 단계에서는 식재료/장보기/식단을 개별 테이블로 분리하고 변경 이력을 두는 것이 좋습니다.
- 현재 로그인 사용자의 첫 번째 가족 공간 하나를 기본 연결합니다. 여러 가족 공간 전환은 후속 기능입니다.
- 오프라인 중 입력한 변경사항은 서버 동기화가 되지 않습니다. 앱 화면 캐시와 데이터 동기화는 별개입니다.
- 브라우저에서 Supabase JS를 CDN으로 불러옵니다. 최초 로딩 및 로그인에는 인터넷 연결이 필요합니다.
- 이메일/비밀번호 인증을 사용하며, 비밀번호 재설정/초대 링크 딥링크/푸시 알림은 아직 구현하지 않았습니다.
- RLS 정책은 가족 구성원만 해당 가족 데이터에 접근하도록 제한합니다. 실제 공개 전 Supabase의 Auth/RLS 테스트를 권장합니다.
