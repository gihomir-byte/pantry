# 냉큼 디자인 시스템 (기초)

지금 앱(`index.html`)은 이 파일들을 불러와요. 예전 색 이름(`--primary` 등)은 새 값을 가리키고, **모든 팝업은 Sheet로 옮겼어요.**
나머지 화면은 하나씩 이 기준으로 옮겨요.

| 파일 | 하는 일 |
|---|---|
| `tokens.css` | 색·간격·글자·둥글기·그림자·움직임 값 (밝게 + 어둡게) |
| `components.css` | 공통 컴포넌트 8종의 모양 |
| `nk.js` | 컴포넌트 HTML 만들기 + 로딩 잠금, 에러 문구, 토스트 (`window.nk`) |
| `copy-guide.md` | 문구 규칙 + 낱말 사전 |
| `preview.html` | 모든 토큰·컴포넌트를 한 화면에서 보기 (밝게/어둡게 전환) |

배포 뒤 `/design-system/preview.html`로 열 수 있어요.

## 1. 토큰을 이렇게 정한 이유

원칙: **지금 코드에서 가장 많이 쓴 값을 기준으로** 골라서, 옮길 때 화면이 거의 안 바뀌게 했어요. 진단에서 문제였던 값(대비 부족, iOS 확대)만 고쳤어요.

### 색
| 토큰 | 값 | 이유 |
|---|---|---|
| 브랜드 `--nk-brand` | `#087F6D` | 지금 버튼·링크에 가장 많이 쓰는 `--primary` 그대로. 흰 글자 대비 4.9:1 |
| 브랜드 연한 배경 위 글자 `--nk-brand-ink` | `#065F52` | 지금 `#087F6D`를 연한 민트 위에 쓰면 4.36:1로 기준 미달이라 한 단계 진하게 (6.7:1) |
| 로고 `--nk-logo` | `#12B89A` | 로고 느낌은 지키되, 흰 글자 대비가 2.5:1이라 **로고 전용**으로 묶었어요 |
| 회색 10단계 | 50~900 | 50·100·200·900은 지금 값 그대로(`#F4F7F6`, `#EBF0EE`, `#E4EAE8`, `#16201E`). 보조 글자 600은 `#66726F` → `#5F6B68`로 살짝 진하게 (회색 바탕 위에서도 4.8:1) |
| 성공 | = 브랜드 | 비슷한 초록이 두 개면 오히려 헷갈려요 |
| 경고 / 오류 | 글자 `#9A5B00` / `#C5282F` | 지금 쓰는 `--warn-ink`, `--danger-ink` 그대로. 막대·아이콘용 경고색만 `#E8890C`(2.6:1) → `#C46A00`(3.9:1) |
| 정보 | `#1F5FD1` | 지금 없던 색. "새로 들어왔어요" 같은 중립 안내용 |
| 다크모드 | 별도 값 | 모든 글자 조합 4.5:1 이상으로 계산해서 정했어요 |

**빠진 색:** 아기 탭 주황(`#F26A2E`), 연속 기록 주황(`#C2410C`), 알림 점 빨강(`#E5484D`) 등 토큰 밖 색 18종은 넣지 않았어요. 옮길 때 브랜드·경고·오류 중 하나로 바꿔요. (아기 주황은 흰 글자 대비 3.05:1이라 그대로 쓸 수 없어요.)

### 간격 — 4, 8, 12, 16, 20, 24, 32, 40px
- 지금 가장 많이 쓴 값이 12px(87곳), 8px(55곳)이라 기준과 잘 맞아요.
- 10px(69곳)은 8 또는 12로, 6px(52곳)은 4 또는 8로, 14px(28곳)은 12 또는 16으로 옮겨요.
- **화면 좌우 여백은 16px 하나**(`--nk-gutter`). 지금 폰에서 이미 16px이라 폰 화면은 그대로예요.
- 누르는 것의 최소 크기 44px(`--nk-touch`)도 함께 정했어요.

### 글자 — 5단계 + 예외 2개
| 단계 | 크기 / 줄간격 / 굵기 | 지금 무엇을 대신해요 |
|---|---|---|
| 제목 | 22 / 1.35 / 700 | 화면 제목 24·25px (폰에서는 이미 22px) |
| 부제목 | 17 / 1.4 / 700 | 카드 제목 16px, 팝업 제목 19px, 첫 화면 카드 17px |
| 본문 | 15 / 1.55 / 400 | 14·14.5·15px (14px가 가장 많지만, 15px가 한글 본문으로 더 편해요) |
| 보조 | 13 / 1.5 / 400 | 12.5·13·13.5px |
| 캡션 | 12 / 1.45 / 600 | 10·10.5·11·11.5·12px (12px 미만은 없애요) |

- **굵기 3종:** 400 / 600 / 700. 지금 많이 쓰던 800은 700으로, 500은 400으로 합쳐요.
- **예외 1 — 숫자 전용 28px:** 가계부 합계(30px), 초대 번호(32px), 개수(40px)처럼 숫자만 크게 보여 줄 때. 글자 단계에 억지로 넣으면 제목보다 숫자가 작아져서 오히려 위계가 무너져요.
- **예외 2 — 입력칸 16px:** 16px보다 작으면 아이폰이 입력칸을 누를 때마다 화면을 확대해요 (진단에서 '상' 문제).
- 지금 31종이던 글자 크기가 **5 + 2종**으로 줄어요.

### 둥글기 3단계 — 8 / 12 / 20px
- 8px(버튼·입력칸·칩·줄): 지금 가장 많이 쓴 값(36곳).
- 12px(카드): 지금 카드 값 그대로(15곳).
- 20px(아래 시트·큰 팝업): 지금 16px보다 조금 키워 카드와 확실히 구분돼요.
- 동그라미(아바타·점)는 '모양'이라 단계에 넣지 않았어요.
- 지금 4·6px(작은 알약·탭)은 8px로 합쳐요.

### 그림자 2단계
- 1단계: 살짝 뜬 것 (선택된 분리 버튼). 지금 `.seg button.on`과 같아요.
- 2단계: 위에 떠 있는 것 (시트, 토스트). 지금 팝업 그림자(`0 20px 70px`)를 조금 줄여 덜 무겁게.
- 카드에는 그림자를 쓰지 않아요. 지금처럼 얇은 테두리로 구분해요.

### 움직임 — 150ms / 250ms
- 150ms: 누름, 색 바뀜, 체크
- 250ms: 시트·토스트가 나타날 때, 화면 바뀔 때
- 폰에서 '동작 줄이기'를 켠 사람에게는 0ms (바로 바뀜)

## 2. 컴포넌트

| 이름 | 클래스 | 도우미 | 진단에서 무엇을 고쳐요 |
|---|---|---|---|
| Button | `.nk-btn` + `--primary` / `--secondary` / `--text`, `--danger`, `--sm`, `--block` | `nk.button()`, `nk.withLoading(btn, fn)` | 버튼 20종 → 3종. 모든 버튼 누름 반응. 로딩 중 잠금으로 **두 번 저장 방지**. 작은 버튼도 누르는 범위 44px. 지우기는 항상 빨간 글자 |
| TextField | `.nk-field`, `__label`, `__input`, `__help`, `__error` | `nk.textField()`, `nk.setFieldError()` | 입력칸 3종 → 1종. 글자 16px. 라벨이 입력칸과 연결돼요. 에러는 칸 바로 아래에 |
| Card | `.nk-card`, `__head`, `__title`, `__desc`, `__list` | `nk.card()` | 카드 3계열 → 1종 (흰 바탕 + 테두리) |
| ListItem | `.nk-list-item`, `__lead`, `__body`, `__title`, `__desc`, `__trail` | `nk.listItem()` | 줄 전체가 눌려요(최소 56px). 긴 이름은 두 줄에서 말줄임 |
| Skeleton | `.nk-skeleton` | `nk.skeleton()` | 불러오는 동안 빈 화면·옛 숫자 대신 자리 표시 |
| EmptyState | `.nk-state` | `nk.emptyState()` | 아이콘 + 제목 + 설명 + 버튼 하나 |
| ErrorState | `.nk-state--error` | `nk.errorState()`, `nk.errorText()` | 개발자 문구 대신 "무슨 일 + 할 일 + 다시 해 보기" |
| Toast | `.nk-toast` | `nk.toast(msg, {actionLabel, onAction})` | 하단 탭·홈 막대 위로. 나타날 때 움직임. 낭독기가 읽어요 |
| Sheet | `.nk-sheet-scrim` > `.nk-sheet` > `__grab`, `__close`, `__body` | `nk.sheet(scrim, {onClose})` → `open(html)`, `close()` | 아래에서 올라오는 움직임, 손잡이 끌어내리기·X·바깥·뒤로가기·Esc로 닫기, 홈 막대 여백, 뒤 화면 스크롤 막기, 닫으면 포커스 돌려주기 |
| (덤) Badge | `.nk-badge--success/warning/danger/info` | | 상태 알약 색을 의미색으로 통일 |

모든 컴포넌트는 밝게/어둡게 둘 다 자동으로 맞춰져요.

## 3. 앱에 옮기는 순서 (다음 단계)

1. ✅ `index.html` `<head>`에 `tokens.css`, `components.css`, `<script src="/design-system/nk.js">`를 넣고, `service-worker.js`의 캐시 목록에도 추가해요.
2. ✅ 지금 `:root` 변수(`--primary`, `--muted` 등)를 새 토큰을 가리키게 바꿔요. (예: `--primary: var(--nk-brand)`) 화면이 거의 그대로인 채로 값만 한곳에 모여요.
3. 화면 하나씩 클래스를 바꿔요: 공통(토스트·✅ 팝업) → 홈 → 냉장고 → 레시피 → 장보기·가계부 → 아기 → 첫 화면.
4. 하드코딩 색 18종, 인라인 `style` 137곳을 정리해요.
5. 모든 화면이 옮겨진 뒤에 `<html data-theme="auto">`로 다크모드를 켜요. 그 전에 켜면 반쯤만 어두워져요. 그래서 지금은 `data-theme`이 `dark` 또는 `auto`일 때만 다크 값이 적용돼요.
