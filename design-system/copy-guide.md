# 냉큼 문구 규칙 (copy-guide)

> 한 줄 원칙: **초등학생이 소리 내어 읽고 바로 따라 할 수 있게.**
> 새 문구를 쓰거나 고칠 때 맨 아래 "올리기 전 점검표"를 꼭 확인해요.

---

## 1. 기본 규칙 5가지

### ① 해요체 하나로
- 모든 문구는 **"~해요 / ~했어요 / ~해 주세요"**로 써요.
- 쓰지 않아요: "~합니다", "~습니다", "~하세요", "~하십시오", 반말("~함", "~됨").
- 서버(Edge Function)가 보내는 문구도 똑같이 해요체로 써요.

| 쓰지 않아요 | 이렇게 써요 |
|---|---|
| 등록할 상품이 없습니다. | 넣을 재료가 없어요. |
| 살 재료를 적어 두고, 산 건 체크하세요. | 살 재료를 적어 두고, 산 건 눌러 주세요. |
| 사진 분석에 실패했습니다. | 사진을 읽지 못했어요. |

### ② 한 문장은 40자 이내
- 띄어쓰기를 포함해서 **40자**를 넘지 않아요. 넘으면 두 문장으로 나누거나 덜어 내요.
- 한 화면의 설명은 **두 문장까지**만 써요.
- 문장 하나에는 **할 일 하나**만 담아요.

| 길거나 어려워요 | 이렇게 줄여요 |
|---|---|
| 영수증, 장 본 재료, 컬리, B마트, 주문 화면 모두 돼요. 여러 장도 가능해요 | 영수증이나 주문 화면을 찍어 주세요. 여러 장도 돼요. |
| 구매한 재료를 구매분별로 관리하고, 먼저 먹어야 할 재료를 확인하세요. | 먼저 먹어야 할 재료가 위에 있어요. |

### ③ 에러는 "무슨 일 + 어떻게 하면 되는지"
- 형식: **[무슨 일이 있었어요.] + [이렇게 해 주세요.]** 그리고 가능하면 **[다시 해 보기]** 버튼.
- 사람 탓을 하지 않아요. ("잘못 입력했어요" ✕ → "번호가 맞지 않아요" ○)
- **절대 보여 주지 않아요:** 영어 원문, 오류 코드(23505, PGRST202, 503…), 파일 이름(config.js), 회사·모델 이름(Gemini, Supabase), "서버 오류", "실패", "예외".
- 원래 오류 내용은 `console`에만 남기고, 화면에는 `nk.errorText(error)`가 만든 문장을 써요.

| 쓰지 않아요 | 이렇게 써요 |
|---|---|
| 서버 오류: JWT expired | 로그인이 풀렸어요. 다시 로그인해 주세요. |
| Gemini 요청 형식 오류: … | 사진을 읽지 못했어요. 글씨가 잘 보이게 다시 찍어 주세요. |
| 들어가지 못했어요. (23505 duplicate key …) | 이미 들어와 있는 냉장고예요. |
| 서버 설정을 확인해 주세요. config.js 파일이 필요해요. | 인터넷이 끊겼어요. 연결되면 다시 열어 주세요. |
| 저장 실패 | 저장하지 못했어요. 연결되면 다시 저장할게요. |

### ④ 버튼은 구체적인 동사로
- 버튼만 읽어도 **눌렀을 때 무슨 일이 생기는지** 알 수 있어야 해요.
- **"확인", "예", "OK", "완료"는 쓰지 않아요.** 대신 "냉장고에 넣기", "저장하기", "장보기에 넣기"처럼 써요.
- 형태: **"~하기"** 또는 **"~에 넣기 / ~ 보기"**. 문장형("~할게요")은 버튼에 쓰지 않아요.
- 두 버튼이 나란히 있으면 왼쪽은 그만두기(취소·나중에), 오른쪽은 하려던 일이에요.
- 지우는 버튼은 무엇을 지우는지 써요. ("삭제" ✕ → "기록 지우기", "가족에서 빼기" ○)

| 쓰지 않아요 | 이렇게 써요 |
|---|---|
| 확인 | 하는 일을 그대로: "재료 확인하기", "냉장고에 넣기" |
| 정보 수정 / 변경 저장 | 고치기 / 고친 내용 저장하기 |
| 이렇게 저장 | 양념 저장하기 |
| 좋아요 (축하 팝업 닫기) | 닫기, 또는 다음 할 일 "가계부 보기" |
| 삭제 | 지우기 |

### ⑤ 같은 것은 늘 같은 이름으로
아래 "낱말 사전"에 있는 말만 써요. 새 낱말이 필요하면 사전에 먼저 추가해요.

## 2. 낱말 사전

| 쓰는 말 ○ | 쓰지 않는 말 ✕ | 메모 |
|---|---|---|
| 재료 | 식재료, 상품, 품목, 식재료명, 상품명 | 영수증의 원래 이름만 "영수증에 적힌 이름" |
| 넣기 / 넣었어요 | 등록, 추가 | 냉장고·장보기 모두 "넣기" |
| 지우기 / 지웠어요 | 삭제, 제거 | 가족은 "빼기" |
| 고치기 | 수정, 변경, 편집 | |
| 산 날 | 구매일, 구매 일자 | |
| 언제까지 먹어야 해요 / ○월 ○일까지 | 소비기한 임박, 유통기한, 만료 | 라벨은 "먹어야 하는 날" |
| 곧 먹어야 해요 | 임박 | |
| 날짜가 지났어요 | 기한 지남, 만료됨 | |
| 날짜 없음 | 날짜 미등록, 미입력 | |
| 살 것 / 장보기 | 구매 예정, 장보기 항목 | |
| 있는 재료 ○개 · 사야 할 재료 ○개 | 보유 재료, 부족 | |
| 몇 개 / 얼마나 | 수량, 단위 | 라벨은 "몇 개 있어요?" |
| 종류 | 분류, 카테고리 | |
| 어디에 둬요? | 보관 위치 | |
| 냉장 · 냉동 · 실온 · 김치냉장고 | | 그대로 써요 |
| 고기 · 생선·해산물 · 채소 · 과일 · 우유·계란 · 기타 | 육류(생선 포함), 유제품(계란 포함) | 생선이 '고기'에 들어가지 않게 |
| 사진 읽는 중이에요 | AI 인식 중, 분석 중 | 사용자는 'AI'가 궁금하지 않아요 |
| 사진으로 넣기 | OCR, 영수증 인식 | |
| 가족이 바꾼 내용이 들어왔어요 | 동기화 완료, 실시간 반영, 가족 변경 반영됨 | 보통은 아예 보여 주지 않아요 |
| 레시피 | 요리 추천, 추천 메뉴 | 탭 이름과 같게 |
| 넉넉해요 · 조금 남았어요 · 거의 없어요 · 다 썼어요 | 요리 3번+, 맛내기만 | 남은 양은 이 네 가지로 |

## 3. 자리별 쓰는 법

| 자리 | 길이 | 규칙 | 예 |
|---|---|---|---|
| 화면 제목 | 15자 이내 | 질문이나 사실 한 줄 | 냉장고에 있는 재료 |
| 카드 제목 | 12자 이내 | 명사로 끝내요 | 곧 먹어야 할 재료 |
| 설명 | 40자 × 2문장 | 이 화면에서 할 수 있는 일 하나 | 사진 한 장이면 한 번에 넣을 수 있어요. |
| 버튼 | 8자 이내 | 동사 "~하기", "~에 넣기" | 냉장고에 넣기 |
| 입력칸 라벨 | 10자 이내 | 질문이면 더 좋아요 | 언제까지 먹어야 해요? |
| 입력 예시 | "예: " + 실제 값 | 설명을 넣지 않아요 | 예: 두부 |
| 필수/선택 | | 필수는 표시하지 않고, 선택만 "(선택)" | 가격 (선택) |
| 토스트 | 25자 이내 | 방금 한 일을 과거형으로 | 두부를 냉장고에 넣었어요 |
| 빈 화면 | 제목 + 설명 1문장 + 버튼 1개 | 왜 비었는지 + 첫 행동 | 냉장고가 비어 있어요 / [사진으로 넣기] |
| 에러 | 제목 + 설명 1문장 + [다시 해 보기] | 무슨 일 + 할 일 | 레시피를 불러오지 못했어요 / 인터넷 연결을 확인하고 다시 해 주세요. |

### 빈 화면과 검색 결과 없음은 다르게
- 처음부터 없음: "냉장고가 비어 있어요" + [사진으로 넣기]
- 검색해서 없음: "'두부'는 냉장고에 없어요" + [검색 지우기]
- 사실이 아닌 칭찬은 하지 않아요. (재료가 0개인데 "잘 관리되고 있어요" ✕)

### 숫자와 날짜
- 날짜: "11월 28일", 요일이 필요하면 "11월 28일 목요일". "2026-11-28" ✕
- 가까운 날: "오늘", "내일", "모레", "3일 뒤"
- 돈: "3,500원", 큰 돈 요약은 "13.2만 원"
- 개수: "3개", "2팩" (숫자와 단위 붙여 쓰기)

### 조사
- 이름 뒤 조사는 받침에 맞춰요: `josa('두부','을/를')` → "두부를". "두부을(를)" ✕

## 4. 올리기 전 점검표

- [ ] 해요체인가요? ("습니다", "하세요"가 없나요?)
- [ ] 한 문장이 40자 이내인가요?
- [ ] 낱말 사전에 없는 한자어·외래어가 없나요? (구매, 등록, 임박, 수정, 동기화, AI…)
- [ ] 에러에 "무슨 일"과 "할 일"이 둘 다 있나요? 영어·코드가 없나요?
- [ ] 버튼이 "확인"이 아니라 구체적인 동사인가요?
- [ ] 같은 것을 다른 화면과 같은 이름으로 불렀나요?
- [ ] 초등학생에게 읽어 줬을 때 되묻지 않을까요?
